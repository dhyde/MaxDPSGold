# MaxDPS.com Gold (WoW Forever)

Release distribution repository for **MaxDPS.com Gold**, an auction house, bag verdict, craft profit, Merchant's Favor, and farming gold/hr addon for World of Warcraft: Forever.

## Install

- **CurseForge:** https://www.curseforge.com/wow/addons/maxdps-com-gold
- **WowUp:** *Get Addons → Install from URL* → `https://github.com/dhyde/MaxDPSGold`
- **Direct download & full guide:** https://maxdps.com/forever/gold-addon

Download the latest zip from [Releases](https://github.com/dhyde/MaxDPSGold/releases/latest).
